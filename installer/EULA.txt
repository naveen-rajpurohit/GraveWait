GraveWait - Terms of Use

By installing GraveWait you agree to the following:

1. WHAT THIS PROGRAM DOES
   GraveWait is a small game that appears as a strip along the bottom of your
   screen. If (and only if) you choose the "Attach to Claude Code" option
   during setup, GraveWait adds hook entries to your Claude Code settings file
   (%USERPROFILE%\.claude\settings.json) so the game launches whenever you
   send a prompt. A backup of your original settings file is written next to
   it the first time. Uninstalling GraveWait removes these hook entries.
   Without that option, GraveWait only runs when you launch it yourself
   (a standalone 4-minute demo mode).

2. DATA
   GraveWait stores its saves, event log and generated audio under
   %LOCALAPPDATA%\GraveWait on your machine. It sends nothing anywhere.
   The event log may contain the first line of prompts you send to Claude
   Code and the text of its permission requests, so the game can display
   them. Delete the folder at any time to remove this data.
